Git: Guía de Supervivencia

Control de versiones para humanos.

¿Qué es Git?

Es un sistema de control de versiones distribuido. Permite rastrear cambios en el código, volver a versiones anteriores y trabajar en equipo sin sobrescribir el trabajo de otros.

Comandos Esenciales

1. Configuración

Verifica la versón de git.

git --version

Establece tu correo.

git config --global user.email "nombredelmail@gmail.com"

Establece tu identidad.

git config --global user.name "Tu Nombre"

2. Iniciar

Crea un nuevo repositorio local.

git init

Establece la URL del repositorio remoto de trabajo.

git remote add origin https://github.com/nombredeusuario/nombredeusuariorepositorio.git

3. Guardar

Prepara y guarda tus cambios. Estos cambios se guardan en el repositorio local.

git add . git commit -m "mensaje"

4. Sincronizar

Sube tus cambios al servidor remoto.

git push origin main

5. Ramas

Cambia el nombre de la rama de trabajo actual.

git branch -m main

Crea una nueva rama.

git branch nueva_rama

Establece la rama de trabajo actual como la nueva rama.

git checkout nueva_rama
